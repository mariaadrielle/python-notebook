# Aprendendo Python do Zero

Projeto desenvolvido para o desafio da DIO de criação de um segundo cérebro com IA utilizando o Gemini Notebook (antigo NotebookLM).

## Objetivo

Utilizar um notebook com IA para estudar Python do zero, esclarecer dúvidas, compreender conceitos fundamentais e organizar materiais de aprendizagem com base em fontes selecionadas.

## Fontes utilizadas

O notebook reúne documentação oficial, livros, PDFs didáticos e cursos em vídeo.

## Diretriz do notebook

Atuar como um assistente de estudos de Python para iniciantes, explicando conceitos de forma clara, utilizando exemplos práticos, fundamentando as respostas nas fontes disponíveis e indicando quando elas não forem suficientes para responder.
